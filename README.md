# FrontendDemoApplication

A React + TypeScript frontend demonstrating Redux Toolkit state management patterns 
including slices, async thunks, and redux-persist.

## Tech Stack
- **UI:** React 18, TypeScript
- **State:** Redux Toolkit, redux-persist
- **Build:** Vite / Create React App

## Key Patterns Demonstrated
- RTK slice setup and reducer composition
- Async thunks for API calls
- Persisted state with redux-persist
- TypeScript-typed store and hooks

## Getting Started
```bash
git clone https://github.com/ben3amer/FrontendDemoApplication
npm install
npm start
